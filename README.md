# Шахматы ♟️

Простой проект по шахматам на Python.

## Правила игры (кратко)

- Играют два игрока: **белые** и **чёрные**, белые начинают.
- Цель — поставить **мат** королю противника.
- Основные фигуры и их ходы:
  - **Король** — на одну клетку в любом направлении.
  - **Ферзь** — на любое число клеток по вертикали, горизонтали и диагонали.
  - **Ладья** — по вертикали и горизонтали.
  - **Слон** — по диагонали.
  - **Конь** — буквой «Г» (2 клетки в одну сторону + 1 в перпендикулярную).
  - **Пешка** — на одну клетку вперёд (с начальной позиции — на две); бьёт по диагонали.

## Как запустить

```bash
python main.py
```
